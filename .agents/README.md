- [agent-instructions.md](agent-instructions.md): original project brief, preserved as historical reference. It may differ from current behavior; consult current instructions and confirmed product decisions before applying it.
- [runbooks/firebase-staging-runbook.md](runbooks/firebase-staging-runbook.md): Firebase Hosting staging implementation handoff for this repository, with a copyable agent prompt and a linked Cloud API developer runbook.
- [../docs/deployment/firebase-staging.md](../docs/deployment/firebase-staging.md): frontend staging contract, required receipt/environment inputs, checks and live acceptance boundaries.

Shared testing documentation and usability evidence remain in `docs/`; runnable tests remain in `tests/`. Paths in the working instructions are relative to the project root.
